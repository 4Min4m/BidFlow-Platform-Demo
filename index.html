overview

One chart, two languages, one trace

BidFlow deploys a polyglot pair of bidding services from a single Helm chart: a Go service validates and forwards each bid, a Ruby service owns the write to Redis. Because one request genuinely crosses that language boundary, OpenTelemetry can trace it end to end — not two services that happen to sit near each other, but one connected call.

Terraform provisions GKE Autopilot, Artifact Registry, and a GCS backup bucket. GitHub Actions builds, immutably tags, and deploys both services with no downloaded credential anywhere in the pipeline — GCP trusts GitHub's own signed tokens instead.

architecture

How a bid moves through the platform

Dotted boundary is the cluster. Both services export spans to Jaeger over OTLP; Redis is snapshotted to Cloud Storage every six hours via GKE Workload Identity — no static key anywhere in that path.
